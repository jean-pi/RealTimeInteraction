Capa 1: Motor de Ejecución & TUI Runtime
Descripción General

El binario `gentle-ai.exe` está construido en Go y utiliza la librería Bubbletea para proveer una interfaz gráfica de consola fluida. Su objetivo principal es asegurar la integridad del espacio de trabajo mediante snapshots comprimidos `.tar.gz` antes de permitir ediciones masivas.

Componentes Clave
Go Language Bubbletea TUI Transactional Backups Tar Snapshot Environment Isolation
Filosofía Arquitectónica

PRINCIPIO: El código no se modifica directamente sobre el sistema de archivos sin una red de seguridad transaccional preexistente.
